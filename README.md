# 📄 DocuCraft Studio — Ultimate Client-Side PDF Suite

**DocuCraft Studio** is a high-performance, ultra-stylish, and 100% private browser-based PDF utility and document management suite. Every action runs locally inside your browser with zero server latency.

Designed and developed by **Atif Shah**.

---

## ✨ Features & Tools Included

- ⚡ **PDF Compressor:** Reduce document file sizes using client-side canvas re-encoding with custom quality presets.
- 📑 **PDF Merger:** Combine multiple PDF documents seamlessly into a single continuous file.
- ✂️ **PDF Splitter:** Extract specific page numbers or custom page ranges instantly.
- 🔄 **PDF Rotator:** Adjust the page orientation of PDF documents by 90°, 180°, or 270°.
- 🔒 **PDF Password Protector:** Encrypt documents with secure user passwords for maximum data protection.
- 🖼️ **Image to PDF:** Compile JPG and PNG image collections into clean PDF files.
- ✍️ **Text to PDF Creator:** Convert formatted notes and text content into professional downloadable PDFs.
- 🌓 **Dark/Light Theme Toggle:** Switch seamlessly between a clean Light view and a modern Dark glassmorphism mode.

---

## 🛠️ Built With

* **HTML5 / CSS3 / JavaScript (ES6+)**
* **PDF-Lib & PDF.js** — Binary PDF manipulation and client-side rendering
* **jsPDF** — Vector PDF generation
* **Font Awesome & Google Fonts** — UI Typography and Icons
